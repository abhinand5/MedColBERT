## 6-Subagent Audit Results

### 1. Query Naturalness — Score: 2.25/5
- 90% structural monoculture (question-word openings)
- 22% exact template matches
- Worst: 86 identical "Does Dodecyl Sulfate, Sodium X" queries
- 95% of patient-role queries indistinguishable from researcher
- 0.04% contraction usage — dead giveaway of temp=0.0 generation
- **Verdict**: Usable for retrieval training after template dedup, needs temp>0 regeneration

### 2. Vocabulary Shift — Score: 10-21/100 per family
- **CRITICAL**: All families score below 21/100 on genuine vocabulary shift
- 36-40% of queries contain exact 3+ word n-grams copied from passages
- Judge labels (99.6% STRONG_SHIFT) are unreliable — dummy judging artifact
- brand_generic has NO actual brand/generic substitution
- Key insight: Generator performs question reformulation, not vocabulary substitution
- **Verdict**: NOT suitable for ColBERT contrastive training in current state. Needs pipeline changes.

### 3. Fact Grounding — Hallucination Rate: 0.9-1.2%
- 9.25% queries have <50% term overlap, but only 10-13% of those are hallucinated
- Overall hallucination rate: ~900-1,200 examples out of 100,867
- 50% threshold: good screening tool but 87-90% false-positive rate
- Fact extraction: excellent (98% verbatim from passages)
- **Verdict**: Strong fact grounding. Low hallucination risk.

### 4. Abbreviation Quality — 52% genuine
- 52% genuine abbreviations, 48% synonym pairs misclassified as abbreviations
- 30% of unique alt_terms have context mismatch (homonym errors)
- 0% UMLS artifacts in abbreviation queries
- Previous noise rate: 93% → Current: 48% (7x improvement, but below 80% threshold)
- Root cause: Full words (MORPHINE, DROWNING, OBESE) labeled as "abbreviations"
- **Verdict**: Improved but needs further filtering of synonym pairs

### 5. Diversity & Coverage — Gaps identified
- abbreviation_to_expanded: 256 rows vs 17-31K for others (120:1 ratio) — P0
- 6 semantic groups with <100 rows — P0
- Role-style confounding (each role locked to one query style) — P1
- 99% consumer_to_clinical, only ~1% other vocab shift types — P1
- Single generator model (gemma-4-31B) — P2
- 8,741 passages have only 1 query — P3
- **Verdict**: Adequate base, needs targeted backfill

### 6. Data Integrity — 97/100 🔒 SAFE
- Zero duplicate example_ids, zero data leakage
- Zero nulls in critical columns
- All 26 columns present and correctly typed
- 1,204 UMLS artifacts repaired (0% remaining)
- term_overlap computed for all rows (mean 0.74)
- Minor: alt_term_overlap 99.75% null (by design), student role 9 rows
- **Verdict**: Production-safe. No data corruption.

## Root Causes

1. **temp=0.0 generation** → template monoculture, no lexical diversity
2. **Dummy judge system** → inflated STRONG_SHIFT labels, no real QC
3. **Question reformulation vs vocabulary substitution** → queries copy passage language
4. **UMLS abbreviation flag unreliability** → 48% synonym pairs mislabeled
5. **Single model bias** → all queries share Gemma-4-31B distribution

## Code Fixes Applied (This Session)

All fixes are in place for future generation batches:
- Temp: 0.2 (fact), 0.7 (questions), 0.8 (keywords)
- Diversified prompts with deictic avoidance
- Deterministic Q4 term-overlap check
- Post-generation term-overlap rejection filter
- Fuzzy alt_term matching in validators
- UMLS qualifier stripping in abbreviation prep
- Abbreviation ≥2x filter, T080/T081 removal, context-aware expansion
- Data integrity: null backfills, artifact repair, leakage removal
